# Sandra Boutique 🛍️

E-commerce de moda feminina desenvolvido em JavaScript.

## Features
- Vitrine de produtos
- Carrinho de compras
- Checkout integrado
- Painel administrativo

## Stack
- JavaScript
- HTML5 & CSS3
- Node.js

## Run
```bash
npm install
npm start
```
